
+Shoe Inventory Control

Console-based inventory management system developed in C#.

+Description

This application allows users to manage a shoe inventory through a console interface.

+Planned Features

- Register shoes.
- Search shoes by different criteria.
- Modify shoe information and stock.
- Delete shoes.
- List registered shoes.

+Technologies

- C#
- .NET
- Git
- GitHub

+Project Status

Initial development.
